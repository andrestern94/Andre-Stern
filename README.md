# Tarkvaraarenduse ja koodihalduse alused (LTAT.02.031)

See repositoorium on loodud Tartu Ülikooli aine
„Tarkvaraarenduse ja koodihalduse alused" materjalide
ja ülesannete jaoks.

Repo eesmärk on hoida ühes kohas kursuse jooksul loodud
koodi, harjutusi ja muid õppematerjale ning praktiseerida
Git'i ja versioonihalduse kasutamist.

Mul ei ole varasemat programmeerimiskogemust ning see repo on ühtlasi minu päris esimene kokkupuude versioonihaldusega.

README on jooksev dokument ning seda täiendan kursust läbides.

## Dockeri harjutus 23.09.2026

Image'i loomine (kaustas, kus asub Dockerfile):
    docker build -t myapp .

Konteineri käivitamine:
    docker run myapp

Vastuseks tuli:
    "Tere Dockerist!"

Samuti esines probleeme Dockeriga - nimelt ei käivitunud Docker (Virtualization support not detected - Docker Desktop failed to start because virtualisation support wasn’t detected. Contact your IT admin to enable virtualization or check system requirements.)
